# Retail Sales Analysis

## Project Overview

The Retail Sales Analysis project uses Python and data analysis techniques to explore retail sales data and generate business insights. The project demonstrates data cleaning, revenue calculations, data visualization, and business decision-making using a real-world style dataset.

This project was completed as part of the Melsoft Academy Data Science programme and incorporates concepts from Python Essentials 1 and Python Essentials 2.

---

## Objectives

The objectives of this project were to:

- Load and explore retail sales data.
- Clean and prepare the dataset for analysis.
- Identify and handle invalid or missing values.
- Calculate revenue for each transaction.
- Analyse sales performance across stores and categories.
- Visualise sales trends using charts.
- Generate business insights and recommendations.
- Demonstrate reusable Python code using functions and modules.

---

## Dataset Description

The dataset contains retail sales transactions and includes information such as:

- Product Name
- Category
- Quantity Sold
- Unit Price
- Store Location
- Payment Method

The data was analysed using Python and Pandas.

## Data Cleaning

The following cleaning steps were performed:

- Converted the `unit_price` column to numeric values.
- Handled invalid values such as `"unknown"`.
- Standardised store names by removing extra spaces.
- Corrected inconsistent capitalisation.
- Created a revenue column using:

```python
sales["revenue"] = sales["quantity"] * sales["unit_price"]
```

---

## Revenue Analysis

### Total Revenue

The total revenue generated by the dataset was:

**R324,251.00**

Revenue was calculated by multiplying the quantity sold by the unit price of each product.

---

## Visualisations

The project includes visualisations for:

- Revenue by Store
- Revenue by Category

Charts were generated using Matplotlib and saved automatically to the `data/charts` folder.

---

## Key Findings

- Total revenue generated: R324,251.00
- Revenue varied across store locations.
- Sandton was the highest-performing store.
- Rosebank generated the lowest revenue.
- Product categories contributed differently to overall revenue.
- Best-selling products played a significant role in total sales performance.

---

## Business Recommendations

Based on the analysis, the following recommendations can be made:

- Maintain stock levels for top-performing products.
- Focus marketing efforts on high-performing categories.
- Investigate reasons for lower performance in some stores.
- Use sales data to improve inventory planning.
- Continue monitoring revenue trends through regular reporting.

## Reusable Python Functions

To improve code quality and demonstrate Python Essentials skills, repeated tasks were moved into a separate module called `helpers.py`.

### Functions Created

#### load_and_clean_data()

Loads the dataset and performs:

- Data loading
- Data cleaning
- Unit price conversion
- Store name standardisation
- Revenue calculation

#### save_chart()

Handles chart formatting and saves visualisations to the charts folder.
